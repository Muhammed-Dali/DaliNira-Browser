DaliNira includes bundled prebuilt blocker ruleset JSON and scripting assets for
local request filtering, cosmetic filtering, scriptlet execution, and developer
inspection.

Source snapshot:
uBlock Origin Lite-compatible rulesets exported from a local reference checkout.
The exact generator/source commit for the pre-existing bulk snapshot is not
recorded in this tree and requires human provenance review before redistribution.

Included ruleset metadata:
- ruleset-details.json
- ruleset-attributions.json (immutable ID to official name, provider, source,
  license status, and manual-review status)

Included ruleset directories:
- main/*.json
- regex/*.json
- strictblock/*.json
- scripting/generic/*.js
- scripting/generichigh/*.css
- scripting/popup/*.js
- scripting/specific/*.{js,json}
- scripting/procedural/*.{js,json}
- scripting/scriptlet/main/*.js
- scripting/scriptlet/isolated/*.js
- urlskip/*.json (packaged upstream data; not consumed by the native runtime)

These rulesets originate from upstream filter-list build outputs adapted for
DaliNira. Keep this notice with the bundled resources and review upstream
licenses before redistribution.

  cosmetic/scriptlet assets. The generated format and the underlying filter
  list provider are distinct provenance layers.
