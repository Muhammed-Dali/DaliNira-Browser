Dual engine

Choose your engine. Keep your browser.

DaliNira 8.0 runs on Chromium through Qt WebEngine or on WebKitGTK. Both use the same DaliNira interface.

Settings → System

Switch engines from Settings

Switching engines restarts DaliNira and opens that engine's own tabs. Automated parity tests run the same scenarios against both engines and compare the results.

  • Shared interface: toolbar, menus, find bar, translation, blocker, permissions and downloads.
  • Separate workspaces: tabs, session and Quick Access are kept per engine.
  • Chromium runs natively on Wayland; WebKitGTK runs through XWayland.
  • WebKitGTK runs on DaliNira's own patched WebKitGTK 2.54.1, installed only for DaliNira; the system WebKitGTK is not used.

Ad and tracker shield

Cleaner pages without extensions

The DaliNira blocker applies filter lists locally, hides empty ad containers and removes tracking parameters such as utm_*, fbclid and gclid.

  • Protection levels, list selection and per-site exceptions.
  • The same filtering engine for Chromium and WebKitGTK.
Downloads

All downloads in one place

Segmented parallel downloads with resume and retries, plus media analysis for supported sites.

  • Paste a link and analyze it, or download the media on the current page.
  • Active downloads and history on dalinira://downloads.
Password vault

Passwords stay on this device

An optional, experimental vault encrypts the logins you approve with AES-256-GCM and a PBKDF2-HMAC-SHA256 key.

  • Never synchronized to a server, with no developer back door.
  • Turned on only after you read the notice and agree.
Audio

Studio tools for web media

Route web audio through a 32-band equalizer, compressor, limiter and stereo widener, with 1,757 AutoEQ headphone presets.

  • Presets for Sony, Sennheiser, Beyerdynamic, AKG, Apple and more.
  • One switch turns sound effects on or off for web media.
Pulse

Name the song that is playing

Pulse identifies the song playing on your computer. It builds an audio fingerprint locally and sends only that fingerprint to Shazam's recognition service.

  • System audio, the microphone, or both as the source.
  • A list of the songs Pulse has found.
Privacy principles

Your data stays on your computer

Concrete design decisions instead of marketing claims.

Local first

History, bookmarks, passwords, settings and presets are stored in your user profile on your computer.

No account, no telemetry

DaliNira needs no sign-in and has no built-in usage telemetry.

Network only when needed

Search suggestions, translation, Pulse recognition and filter-list updates contact only the service that feature needs.

Encrypted password vault

Credentials are encrypted locally with AES-256-GCM and a PBKDF2-HMAC-SHA256 key, and are never synchronized.

A website without trackers

This site loads no analytics, no cookies and no external fonts or scripts, and uses a strict Content Security Policy.

Install DaliNira 8.0.2

DaliNira supports Linux x86_64. Releases are built for Debian, Ubuntu, Fedora and Arch Linux, plus a portable archive; before a release is published, each native package is installed and checked in a clean container.
