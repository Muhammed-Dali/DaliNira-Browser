DaliNira Pacman Repository

All packages are cryptographically signed. First, import and trust the GPG signing key:

curl -sL https://muhammed-dali.github.io/DaliNira-Browser/dalinira.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key BC741FD0AC804351B0DDBB86FDFEC60C11202588

Add the following repository to /etc/pacman.conf:

[dalinira]
SigLevel = Required DatabaseOptional
Server = https://muhammed-dali.github.io/DaliNira-Browser/x86_64

Then install with sudo pacman -Syu dalinira.
